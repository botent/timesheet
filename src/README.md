## The core features -

1. Start a task and a timer with it. The timer can be paused and stopped. If the task is marked as Finished, the timer count is summed and shown next to it.
2. The tasks are saved / shown in a date desc order
3. Using SQLite, this can be managed with lightness

## Components Needed

1. A component to create tasks - form based
2. A component to display tasks and manage inline the status + show timer
